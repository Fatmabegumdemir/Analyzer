# Analyzer kullanıcı arayüzü

Angular tabanlı belge yükleme, karşılaştırma ve CSV dışa aktarma arayüzü.

Kurulum, API ayarları ve kullanım için [ana README](../../README.md) dosyasına bakın.

```sh
npm ci
npm start
npm run build
npm test -- --watch=false
```

Geliştirme sunucusu: http://localhost:4200. `/api` istekleri `proxy.conf.json` üzerinden http://localhost:5000 adresine yönlendirilir.
